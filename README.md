## Запуск (физический Android)

1. На телефоне: режим разработчика + USB-отладка (или Wi‑Fi debugging).
2. Подключить USB, проверить устройство:

```powershell
$env:PATH = "D:\projects\LARNES-2.0\.tools\flutter\bin;" + $env:PATH
cd larnes-mobile
flutter pub get
flutter devices
flutter run
```

По умолчанию **debug** ходит в prod API: `https://larnes.ru` (та же БД, что web на VPS). Отдельный флаг не нужен.

Release-сборки — тоже `https://larnes.ru`.

```powershell
flutter pub get
flutter build apk --release
```

Перед каждой новой публикацией **до сборки** увеличить versionName и versionCode в pubspec.yaml (текущая версия — в pubspec.yaml). После сборки проверять versionName/versionCode внутри фактического APK, а не только имя файла; код должен быть больше номера установленного обновления и не повторять загруженные версии. Для админки выдавать отдельный файл с версией в имени, чтобы исключить выбор старого app-release.apk.

APK: `build/app/outputs/flutter-apk/app-release.apk`

Обновление планшета выполняется поверх установленного приложения: `adb install -r build/app/outputs/flutter-apk/app-release.apk`. Регистрация девайса и настройки сохраняются. Перед пилотом проверьте одинаковую подпись старого и нового APK; если Android сообщает о несовпадении подписи, используйте исходный ключ сборки. Не удаляйте приложение для обхода этой ошибки: удаление стирает локальную регистрацию.

## API: когда какой backend

| Сценарий | Команда |
|----------|---------|
| **Обычная разработка UI** (телефон) | `flutter run` |
| **Локальный `platform/`** на ноуте (своя БД) | см. ниже |
| **Android-эмулятор** + локальный Next.js | `--dart-define=API_BASE_URL=http://10.0.2.2:3200` |

### Локальный platform + телефон (одна Wi‑Fi)

`localhost` на телефоне — это сам телефон, не ноут. Нужен **LAN IP ноута**:

```powershell
ipconfig
# IPv4, например 192.168.1.42
```

Backend слушает сеть (не только 127.0.0.1):

```powershell
cd platform
npx next dev -H 0.0.0.0 -p 3200
```

Разрешить порт 3200 в firewall Windows, если не коннектится.

```powershell
cd larnes-mobile
flutter run --dart-define=API_BASE_URL=http://192.168.1.42:3200
```

HTTP на LAN: в Android уже `usesCleartextTraffic="true"`.

### Эмулятор (если понадобится)

```powershell
flutter run -d emulator-5554 --dart-define=API_BASE_URL=http://10.0.2.2:3200
```

### Обновление приложения — актуализация 2026-10-31, прогон 28

Во время обновления приложения из 1.0.10 диалог ещё прежний: новый интерфейс станет доступен после установки 1.0.11. Фоновое скачивание после принудительного убийства процесса и собственный installer здесь не реализованы. Серверный API и админская публикация прежние. Подробности и доказательства — [прогон 28](../platform/docs/active/trainers-polish-v1.md#прогон-28--чистый-интерфейс-персональных-тренажёров-и-понятное-обновление-android-2026-10-31).
